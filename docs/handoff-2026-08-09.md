### 1. The fork-content oracle — highest leverage, not built

the gap that makes bulk per-file convergence unsafe and every merge resolution a
judgement call.

  permissive check that passes vacuously is worse than no check (see trap 4).

Do this before any bulk convergence pass. With it, "which side is this?" becomes a
grep instead of archaeology.

## Traps from this session — all cost real time

1. **A clean audit run may mean the detector is broken.** Always prove it fires
   before trusting silence. `check_upstream_deletions.py` was validated by
   re-staging `video_generate.py`; the non-Python hunk scan by re-breaking
   `requirements.txt`. The first validation attempt was itself wrong — the file was
   untracked and the script reads the git **index**.
2. **A threshold tuned for one file class silently disables another.** Extending
   `find_dropped_hunks.py`'s pathspec to docs/config changed *nothing* until
   `--min-lines` was split per class: a dropped `mlx>=0.32.0` is one line and 100%
   of that commit's contribution.
3. **`app.routes` no longer lists routes added via `include_router()`.**
   FastAPI ≥0.141 inserts one lazy `_IncludedRouter` node; `requirements.txt` pins
   `fastapi>=0.95.1` unpinned. Assert reachability (request is not 404), never
   registration. Do **not** "fix" the fastapi pin — it is byte-identical to upstream.
4. **A vacuous assertion passes.** An AST guard used `inspect.cleandoc` (a docstring
   helper) to dedent method source; `ast.parse` raised, the walk found nothing, and
   the test passed for the wrong reason. Caught only because it failed *with* the fix
   applied. Use `textwrap.dedent`, and always run a new guard both ways.
5. **A test can be edited to tolerate its own bug.** `test_models.py` had
   `assertEqual(shape, (3,1,1))` weakened to `assertIn(shape, {(1,1),(3,1,1)})`.
   AST-diff *bodies* of shared functions, not just `def` names.
6. **Background jobs mutate the working tree.** A validation job that `sed`s a file
   and restores it will collide with edits made while it runs. Check `git diff`
   before staging if anything ran in the background.
7. **`import mlx_vlm.convert` gives the re-exported *function*, not the module**
   (`mlx_vlm/__init__.py` shadows it). Use `importlib.import_module`.
8. **Prune `.symbol-exclusions` in the same commit as the restore.** The stale-entry
   warning has caught forgotten prunes three times, once spanning two commits.
