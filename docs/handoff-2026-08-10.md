## Traps from this session — all cost real time

1. **`cd` persists between tool calls, and a wrong relative path returns *empty
   output*, not an error.** This bit **three times**: `git log`/`ls-tree`/`git diff`
   resolving against `mlx_vlm/mlx_vlm/` made two files look fork-only and once
   looked like "byte-identical to upstream". Use `git -C <repo>` unconditionally.
2. **`mlx_vlm.generate` is the re-exported *function*, not the module** — so
   `import mlx_vlm.generate.ar` fails with a confusing `ImportError` and
   `from mlx_vlm.server import app` hands back the FastAPI instance. Use
   `importlib.import_module`.
3. **`cp` is aliased to `cp -i`.** A restore-from-backup silently did nothing and
   left a neutering edit in the tree. Use `command cp -f`, then check `git status`.
4. **Never read a count off a truncated pipe.** `find_dropped_hunks.py | tail -60`
   was counted as "18 commits"; the real number was 34. It reached a commit message.
5. **"Unreferenced" is not "dead".** autoflake's earlier removal of
   `DEFAULT_DIFFUSION_CONFIDENCE_THRESHOLD` was correct on its own terms and wrong in
   effect: the name was unused *because* `f044f36a` had been dropped, so tidying it
   erased the last evidence of the missing hunk. Before accepting an autoflake
   removal in a diverged file, check whether **upstream** references the name.
6. **A "fully converged" claim about a file says nothing about the feature.**
   `0f359e5` recorded "`apc.py` fully converged with upstream" while all three of its
   new helpers had no call sites. `dev/check_dead_helpers.py` exists for exactly this
   and found a fifth instance in ten seconds.
7. **A rule calibrated on nothing fails its own exemplar.** The fork-marker check
   was first written per-hunk and `models/cache.py` — the one file already following
   the convention — failed it.
8. **"Taking upstream's version broke a test" proves nothing about which side is
   right.** It proves the two sides are internally consistent and you hold half of
   each. Test *all* of a commit's files together.
