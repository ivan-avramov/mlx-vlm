**The technique that cleared four files quickly.** For a file whose divergence is a fork

line is a rewrite; **unequal is the only thing worth investigating**:

```python
# .venv/bin/python - <<'PY'   (set P to the file under review)
import subprocess, difflib, re
P = "mlx_vlm/generate/ar.py"
up = subprocess.run(["git","-C","/Users/ia87221/ws/mlx-vlm","show",
                     f"upstream/main:{P}"], capture_output=True, text=True).stdout
ours = open("/Users/ia87221/ws/mlx-vlm/" + P).read()
d = list(difflib.unified_diff(up.splitlines(), ours.splitlines(), lineterm="", n=0))
missing = [x[1:].strip() for x in d if x.startswith("-") and not x.startswith("---")]
print(f"{len(missing)} missing line(s)")
ids = set()
for line in missing:
    ids.update(re.findall(r"[A-Za-z_][A-Za-z_0-9]{4,}", line))
for i in sorted(ids):
    a, b = ours.count(i), up.count(i)
    if a != b:
        print(f"  {i:44s} ours={a:<4} up={b}")   # <- investigate ONLY these
PY
```

#### The four marker mechanics — all four cost a cycle

1. **The check reads the git INDEX.** An unstaged marker looks missing. `git add` first.
2. **It matches a `# Fork:` COMMENT.** A docstring that says "Fork:" does not count.
3. **The marker must be INSIDE the enclosing definition.** A comment above a `def` is
   module scope and covers only module-scope hunks. A definition with both an in-body
   hunk and an adjacent module-scope one needs BOTH.
4. **isort hoists every comment inside an import's parens onto the header line** and
   joins them with `;`, absorbing what follows. One short inline comment per import
   line, always. (Recorded once, tripped over twice.)

#### Do not chase whitespace probe lines

A `# Fork:` comment placed on a *whitespace* probe line changes the alignment against
upstream and produces a NEW probe line. Chasing it in `test_generate.py` went
10 → 8 → 1 → 2 sites. Its residual 5 sites are all of that kind (blank-line boundaries,
plus one method at a different position inside `TestBatchGenerator` — **both trees have
it**). Either reorder to upstream's positions, or leave the entry. Converging beats
marking where it is cheap: moving `test_capture_rope_deltas_prefers_prompt_kwargs` back
to upstream's class closed two sites at once.

## 3. Tooling gaps the audit found — fix or work around

* **`find_dropped_hunks.py` has three floors, and the documented culprit is the wrong
  one.** `f044f36a` is hidden by **`--min-share 0.5`** (its `generation.py` share is
  45%), not by `--min-lines 3`; `--max-commits 80` is a third floor nobody documented.
  `--min-lines 1` alone does **not** surface it. `--min-lines 1 --min-share 0.05
  --max-commits 400` reports 45 commits and does. Run that wider pass before calling the
  report clean, and **never treat the report's per-commit file list as that commit's file
  set** — use `git show --stat`.

  Confirmed 2026-08-10: the wide pass reports **43** commits against the default
  pass's 12, and every one of §2a's bugs is invisible in the default run
  (`8422ece8`'s remaining 19 lines appear only in the wide one). Treat the default
  pass as decoration. Two further limits, both hit for real: the report cannot see
  **deletions** — `29b6c00b`'s `generation.py` work was a ~105-line removal, so only
  its insertions were listed and `check_upstream_deletions.py` was the check that saw
  the rest — and a commit can be fully closed while still listed. The exclusion
  baselines, not the commit count, are the progress signal.
* **`check_dead_helpers.py` is per-symbol, not per-call-site.** One library caller

  surviving sub-case of the "helper landed, call site dropped" pattern that produced most

  Worse than recorded, and confirmed twice on 2026-08-10: restoring **one** call site

## 6. Traps

1. **Always `git -C /Users/ia87221/ws/mlx-vlm`.** `cd` persists between tool calls and a
   wrong relative path returns **empty output, not an error** — three times it made a
   file look fork-only or look "byte-identical to upstream". Same class: a zsh
   `--include=*.py` glob silently swallows a `grep`, and `| head` reports `exit=0` over a
   hard failure.
2. **Never read a count off a truncated pipe.** Every audit prints its own totals.
3. **`cp` is aliased to `cp -i`.** A restore-from-backup silently did nothing and left a
   neutering edit in the tree. Use `command cp -f`, then check `git status`.
4. **`mlx_vlm.generate` is the re-exported *function*, not the module.**
   `from mlx_vlm.generate import ar` works; `import mlx_vlm.generate.ar as m` and
   attribute access both fail.
5. **"Not an ancestor of `upstream/main`" ≠ fork-authored** (upstream squash-merges).
   Check `git log -1 --format=%an` — this is what rescues §2b.
6. **A partially-restored commit is unfinished.** Both §2a-1 and §2c exist because a
   commit was restored from a report's file list instead of `git show --stat`. Corollary
   added 2026-08-10: for a commit that is mostly `print` -> `logger` conversions, a
   partial restore leaves **no failing test and no audit hit** — `cfcc36d9` was declared
   whole in `682043f5` and was 14 lines short. Confirm by re-running the wide pass after
   the restore and diffing the commit's own added lines against the tree.
7. **A weakened assertion and a legitimate numerical relaxation look identical in a
   diff.** AST-diff bodies and check `memory.md` for a recorded reason. Worse variant,
   found 2026-08-10: a fork test had been edited to assert a **buggy** value (#1402's
   cache key), so the suite actively certified the bug. `only_ours` being empty proves
   nothing; diff the bodies.
8. **The per-commit dropped-hunk report does not tell you how much of a file diverges.**
   It ranks commits it can attribute. Deciding a file was "markable" from it produced the
   wrong call on `turboquant.py` (its two reported commits are closed by review, yet 118
   upstream lines are absent). Use a direct `git diff upstream/main -- <path>` for that
   question, and the identifier-count technique in §2g to classify what it shows.
9. **A marker on a whitespace probe line creates a new probe line.** Chasing them in
   `test_generate.py` went 10 -> 8 -> 1 -> 2 sites. Converge the ordering, or leave the
   file allowlisted with the reason written down.
