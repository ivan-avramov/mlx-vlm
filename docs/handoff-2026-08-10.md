## 3. Tooling gaps the audit found — fix or work around

* **`find_dropped_hunks.py` has three floors, and the documented culprit is the wrong
  one.** `f044f36a` is hidden by **`--min-share 0.5`** (its `generation.py` share is
  45%), not by `--min-lines 3`; `--max-commits 80` is a third floor nobody documented.
  `--min-lines 1` alone does **not** surface it. `--min-lines 1 --min-share 0.05
  --max-commits 400` reports 45 commits and does. Run that wider pass before calling the
  report clean, and **never treat the report's per-commit file list as that commit's file
  set** — use `git show --stat`.
* **`check_dead_helpers.py` is per-symbol, not per-call-site.** One library caller
  satisfies it, so a *second* dropped call site for an already-reachable helper is
  invisible. That is exactly how 2a-1 slipped through: `semantic_extra_hash` has a caller
  in `dispatch.py`, so the check says OK while `ar.py` still doesn't call it. This is the
  surviving sub-case of the "helper landed, call site dropped" pattern that produced most
  of last session's real bugs.

## 6. Traps

1. **Always `git -C /Users/ia87221/ws/mlx-vlm`.** `cd` persists between tool calls and a
   wrong relative path returns **empty output, not an error** — three times it made a
   file look fork-only or look "byte-identical to upstream". Same class: a zsh
   `--include=*.py` glob silently swallows a `grep`, and `| head` reports `exit=0` over a
   hard failure.
2. **Never read a count off a truncated pipe.** Every audit prints its own totals.
3. **`cp` is aliased to `cp -i`.** A restore-from-backup silently did nothing and left a
   neutering edit in the tree. Use `command cp -f`, then check `git status`.
4. **`mlx_vlm.generate` is the re-exported *function*, not the module.**
   `from mlx_vlm.generate import ar` works; `import mlx_vlm.generate.ar as m` and
   attribute access both fail.
5. **"Not an ancestor of `upstream/main`" ≠ fork-authored** (upstream squash-merges).
   Check `git log -1 --format=%an` — this is what rescues §2b.
6. **A partially-restored commit is unfinished.** Both §2a-1 and §2c exist because a
   commit was restored from a report's file list instead of `git show --stat`.
7. **A weakened assertion and a legitimate numerical relaxation look identical in a
   diff.** AST-diff bodies and check `memory.md` for a recorded reason.
