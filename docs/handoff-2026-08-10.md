1. **The check reads the git INDEX.** An unstaged marker looks missing. `git add` first.

5. **"Not an ancestor of `upstream/main`" ≠ fork-authored** (upstream squash-merges).
   Check `git log -1 --format=%an` — this is what rescues §2b.
6. **A partially-restored commit is unfinished.** Both §2a-1 and §2c exist because a
   commit was restored from a report's file list instead of `git show --stat`. Corollary
   added 2026-08-10: for a commit that is mostly `print` -> `logger` conversions, a
   partial restore leaves **no failing test and no audit hit** — `cfcc36d9` was declared
   whole in `682043f5` and was 14 lines short. Confirm by re-running the wide pass after
   the restore and diffing the commit's own added lines against the tree.
7. **A weakened assertion and a legitimate numerical relaxation look identical in a
   diff.** AST-diff bodies and check `memory.md` for a recorded reason. Worse variant,
   found 2026-08-10: a fork test had been edited to assert a **buggy** value (#1402's
   cache key), so the suite actively certified the bug. `only_ours` being empty proves
   nothing; diff the bodies.
8. **The per-commit dropped-hunk report does not tell you how much of a file diverges.**
   It ranks commits it can attribute. Deciding a file was "markable" from it produced the
   wrong call on `turboquant.py` (its two reported commits are closed by review, yet 118
   upstream lines are absent). Use a direct `git diff upstream/main -- <path>` for that
   question, and the identifier-count technique in §2g to classify what it shows.
9. **A marker on a whitespace probe line creates a new probe line.** Chasing them in
   `test_generate.py` went 10 -> 8 -> 1 -> 2 sites. **Converge the ordering** — resolved
   2026-08-09, 5 sites -> 0; see §2g. And check `git diff -U0` before assuming a residual
   site IS a probe: `dispatch.py`'s last one is a deletion-only hunk for two legitimately
   absent symbols, which no marker can cover and no reorder can fix.
10. **A line-count delta measures ALIGNMENT, not CONTENT.** Added 2026-08-09, and it is
    the general form of trap 8 and of AGENTS.md's first rule. `apc.py` read as 554
    missing lines / 36 sites / 75 hunks and was a reordering with four hunks of fork
    content. Every wrong claim in this document's history has been a number or a framing
    derived from a line count. AST-diff the bodies (§2g).
11. **"Not missing" is not "not dropped".** `turboquant.py`'s `#1433` and
    `qwen3_5/language.py`'s `#1598` were both *narrowings and refactors* that upstream
    had already removed — nothing was absent, so no report could list them and no
    identifier count could flag them. Only comparing the shared body against upstream's
    finds this shape, and it is invisible to all five audits.
12. **A "RESOLVED" note can be one half short, and the note is then why nobody looks
    again.** `.deletion-exclusions` recorded `7fbc7bc9` as restored and listed three
    symbols it had verified *present* — but #1598's missing half was a *rewrite of a
    fourth symbol that was present all along*. Presence of a symbol says nothing about
    whether its body is upstream's. Same shape in the same file for
    `normalize_audio_features`, whose one-line entry described a one-symbol revert that
    was actually a two-region one, hiding a hard `load_model` crash. **When you write a
    RESOLVED note, name the region and say which sub-parts remain open.**
